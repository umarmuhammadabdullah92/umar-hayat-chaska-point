# Images

Every dish on the menu has a photo slot. The frame is a fixed **4:3** and
stays that size whether or not a photo is there, so the grid cannot
reflow and the Add to cart button stays put when the photos land.

## Adding a photo

Name the file after the dish's id in the `ITEMS` list in `build.py` and
put it in this folder:

    img/<dish-id>.jpg

Then run:

```bash
python3 build.py
```

That is the whole procedure. `.jpg`, `.jpeg`, `.png`, `.webp` and `.avif`
are all picked up, and the build finds the first extension that exists.
The slot fills in on its own, with no markup to edit.

The id is the first field of the item, so `Samosa` is:

    ('samosa-fried','Samosa','fried',999,[], 'Fried pastry.'),   ->  img/samosa-fried.jpg

Until a file exists, the slot shows the dish name on a pale hatched
ground, which looks deliberate rather than broken.

**Square or tall photos will be centre-cropped** to 4:3, because the slot
uses `object-fit:cover`. Shoot or crop to roughly 4:3 (a 1200x900 export
is ideal) or the sides of the dish will be cut off.

## The share card

`og:image` is what WhatsApp, Facebook, X and iMessage show when someone
shares a link to the site. It is separate from the dish photos and
currently points at the logo, which renders as a small, badly cropped
square. Drop a **1200x630** image here as:

    img/social.jpg

Until that file exists the logo is used, which is better than a broken
preview but not good. This is the highest-value image on the site.

## Do not hand-edit the HTML

Every page is regenerated by `python3 build.py`. Anything typed into
`index.html` is overwritten on the next build.
